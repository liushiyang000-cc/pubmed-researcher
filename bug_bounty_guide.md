# Bug Bounty Earning Guide

## Top Platforms

### 1. HackerOne
URL: https://hackerone.com
Bounties: $50 - $100,000+ per bug

### 2. Bugcrowd
URL: https://bugcrowd.com
Bounties: $100 - $50,000+ per bug

### 3. Open Bug Bounty (Easiest)
URL: https://openbugbounty.org
Bounties: $10 - $500 per bug

### 4. Intigriti (Europe)
URL: https://intigriti.com
Bounties: $50 - $10,000 per bug

## 30-Day Path
Week 1: Register HackerOne/Bugcrowd, study OWASP Top 10, practice on portswigger.net
Week 2: Start Open Bug Bounty, test small sites
Week 3-4: Submit reports, get first $50-200
